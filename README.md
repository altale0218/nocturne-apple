# Nocturne for iPhone and iPad

The native Nocturne client for iOS and iPadOS. Open Nocturne.xcodeproj in Xcode or run the Apple unsigned build workflow to produce a development IPA. The IPA requires signing before device installation.

This repository includes the Apple app, its tests and the build workflow. It is currently a development release.

Tags beginning with \`nocturne-apple-ci-device-\` build a device-only IPA. The build report identifies this mode, and simulator tests remain part of the regular workflow.
